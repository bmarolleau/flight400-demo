Exercise 7
Generate a React Carbon App from a Green Screen
Use Bob in IBM i Developer mode to analyze the FLIGHT400 5250 screen and generate a modern React web application styled with IBM Carbon, running directly on IBM i PASE.
~30 min Optional IBM i Developer mode
Use Bob to analyze the FLIGHT400 Create Order 5250 screen and generate a full React 18 + Vite app styled with IBM Carbon, running natively in IBM i PASE. This is an optional warm-up — it takes about 30 minutes.
1
Create a Helper Skill (Sharpen Your Skill)

Before generating the React app, give Bob extra context about running React + Vite on IBM i PASE by creating a small helper Skill.

1
Open a new task in Agent mode
In Agent mode, click the + button (top right) and select Local Workspace as the task context.
2
Paste the SAMPLE-SKILL.md content and create the skill
Open SAMPLE-SKILL.md from your workspace, copy its entire content, paste it into the Bob chat, then append this instruction and send:
Create a skill from the pasted text.
2
Generate the React App

Switch to IBM i Developer mode, then click the + button and select your FLGHT4nn library list as the context. Drag or paste the FLIGHT400 screenshot below into the Bob chat prompt, then replace 4nn and 30nn with your assigned numbers and send.

Paste or drag this screenshot of the FLIGHT400 Create Order screen into the Bob prompt
Given this screenshot of the 5250 flight order screen from the Application Flight4nn in @FLGHT4nn, Build a single-page React 18 + Vite 4 app on IBM i (PASE) using @carbon/react ^1.x with the g100 dark theme that modernises the IBM i 5250 screen shown in the attached screenshot. Create the app in the IFS at $HOME/flight4nn-frontend-apps/screen-name/. Use the g100 dark theme. All fields should have a list of values to select from. The dev server must run in the background using nohup … & and write output to /tmp/vite-dev.log. Pin the Vite dev server to port 30nn if available.
Example result — React Carbon app modernising a 5250 screen
3
Start the App and Open It in Your Browser

After Bob generates the files, ask Bob to start the dev server for you:

Please start the dev server for the app you just created.

Then open http://localhost:30nn in your browser — replacing 30nn with your Dev Port from the Setup table.

💡 Nothing showing in your browser? Make sure you have completed Step 2 of Environment Setup (the SSH tunnel) and that it includes your port number. Note that the port number and the look & feel of the generated app may differ from any examples shown.
