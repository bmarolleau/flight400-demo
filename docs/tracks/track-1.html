Exercise 1
Code Explanation & Architecture Documentation
Use Bob to automatically generate an architecture overview with Mermaid diagrams, then switch to Database mode to produce an Entity Relationship Diagram of the FLGHT4nn database.
~30 min IBM i Developer mode IBM i Database mode
Generate a living architecture document and ERD from the legacy FLGHT4nn codebase — no manual reverse-engineering required.
1
1a — Browse the Application in the Object Browser

Explore the FLGHT4nn library structure before generating documentation.

1
Expand your library in the Object Browser
In the IBM i sidebar, expand User Library List and Object Browser. Add a filter for FLGHT4nn in the object browser if not already done so, and set the filter to *ALL so you see all object types: *PGM (RPG and CL programs), *FILE (display and database files), *MENU (application menus).
⚠️ Use *ALL, not * — the wildcard * does not work for filtering object types in the Object Browser. You must type *ALL exactly.
2
Browse source members and preview a display file
Expand Source Files and open a few programs from QRPGSRC. Then navigate to QDDSSRCD and open FRS001DF. Click Preview All on the first line to see the green-screen layout rendered visually. Try FRS021DF as well — this is the Flight Maintenance screen used in Exercise 3.
3
Check how old the programs are
In the Object Browser, click on the program FRS000.pgm — that is the flight reservation logon. You'll see in the Detail that this program was compiled in 1997, over 30 years ago!
2
1b — Generate an Architecture Explanation with Bob

Switch to IBM i Developer mode. Click the + (Scope) button and select (QSYS) Library List as the context scope. Make sure FLGHT4nn is in the library list. Replace nn with your library number in the prompt below.

Generate a comprehensive architecture overview of the FLGHT4nn application in QSYS in Markdown format. Include a high-level description, the main program flows, key programs and their roles, a Mermaid architecture diagram, and a summary of the database tables used.

Bob will analyze the programs, source members, and database files and return a structured Markdown document. Review the output — notice how it identifies the menu-driven architecture, the core transaction programs, and the underlying database schema.

Copy the output to a new file FLGHT4nn-Architecture.md in your workspace for reference.
3
1c — Generate an Entity Relationship Diagram

Switch to IBM i Database mode using the mode selector. Type the slash command below so /erd is highlighted in the Bob chat. Replace 4nn with your number.

/erd FLGHT4nn
Bob will introspect the physical files (FLIGHTS, ORDERS, CUSTOMERS, AGENTS, etc.) and generate a Mermaid ERD. Key relationships: ORDERS links to FLIGHTS, CUSTOMERS, and AGENTS; FLIGHTS references FRCITY and TOCITY. Copy the ERD to your architecture document.
